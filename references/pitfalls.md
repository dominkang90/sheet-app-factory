# 겪은 문제와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 배포 뒤 로그인 화면에서 아무것도 안 됨 | 화면 스크립트 안의 슬래시+별표에서 HtmlService 가 코드를 잘라 버림 | build.py 검사. `'image/*'` 같은 글자도 `\u002a` 로 |
| 사진 넘길 때 몇 초씩 걸림 | 넘길 때마다 원본을 통째로 받음 | `getImagesSized`(드라이브 썸네일 링크 `=s{px}`, fetchAll, 6시간 캐시) + 다음 사진 미리 받기 |
| 앨범 크게 보기 느림 | 같은 원인 | 흐린 작은 그림 먼저 → 화면 크기 그림 → 두 번 누를 때만 원본 |
| 구글 계정 여러 개 로그인된 브라우저에서 서버 호출 실패 | google.script.run 은 로그인 쿠키를 탐 | 쿠키 없이 POST(text/plain JSON) — 틀이 이렇게 함 |
| 검사(Playwright)가 끝나지 않고 멈춤 | `page.evaluate` 로 끝나지 않는 Promise(확인 창 등)를 기다림 | `void modal(...); 0` 처럼 기다리지 않게 |
| 병렬로 검사 여러 개 돌리면 가끔 실패 | 컴퓨터가 느려져 시간 초과 | 실패한 것만 따로 다시 돌려 확인하고, 그렇다고 보고 |
| 알림 줄이 확인 창을 가림 | z-index | `body:has(.ovl[style*="flex"]) .net{opacity:0}` |
| 대표가 참석을 누르니 다른 사람 응답이 바뀜 | upsert 에서 대표는 이름 칸을 강제하지 않았음 | 이름을 안 주면 대표도 자기 줄(틀에 반영) |
| 날짜가 하루 밀림 | 시트가 날짜를 다른 시간대로 해석 | 글자로 저장(`'` 붙임), 스프레드시트 시간대를 schema tz 로 |
| clasp create 뒤 웹앱 설정이 사라짐 | create 가 appsscript.json 을 덮어씀 | deploy.py 가 되돌려 놓음 |
| Vercel 이 프로젝트 이름을 `web` 으로 만듦 | `--yes` 로 바로 deploy | 먼저 `vercel link --yes --project <app.name>` (deploy.py) |
| 드라이브 폴더에 git 저장소를 두니 이상해짐 | 동기화가 .git 을 건드림 | 코드는 `C:\Users\rkdtk\dev\<앱>` (new_app.py 가 드라이브 안을 거절) |
| 틀을 새로 받은 앱이 "권한이 필요해요"로 멈춤 | 틀 업데이트로 권한(oauthScopes)이 늘었음 (예: 주간 백업의 script.scriptapp) | 배포 뒤 편집기에서 `처음_설정`을 한 번 더 실행해 새 권한 승인. 있는 시트·데이터는 그대로 |
| 같은 화면 오류가 여러 줄로 쌓임 | 줄 번호가 다르면 다른 오류로 셈 | 화면은 줄 번호를 뺀 내용으로 한 번만 보내고, 서버도 같은 내용은 6시간 안에 `횟수`만 올림 |
| 모의 화면 그림이 깨져 보임 | 모의 서버가 가짜 그림을 줌 | 실제 주소에서 확인. 보고할 때 구분해서 말하기 |
